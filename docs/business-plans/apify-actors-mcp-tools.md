## How it works

Apify Store lets developers monetize Actors via pay-per-event or pay-per-usage pricing; Apify bills users and keeps a 20% commission. Actors can also be exposed as MCP tools to AI agents, and agents can pay per request. Build tools that use public, ToS-compliant data sources or provide utility (document conversion, enrichment from licensed APIs, workflow automation). Payers are developers, businesses, and AI agents running workloads.

**Platforms:** Apify Store, Apify MCP, other MCP marketplaces (MCPize etc.)
