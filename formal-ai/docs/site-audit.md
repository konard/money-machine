# Website untranslated-span audit

Audit date: 2026-11-04. Node 20.19.4. No commits were made.

## Method and limits

Ran the actual sentence harness on seeds **17, 42 and 73, 40 sentences each**, then seed **99, 30 sentences** as a separate regression check. The sampling pool contained 18,770 units from website/strategies.json and docs/**/*.md. Ran the actual translate CLI with --file and --json on the complete pages docs/business-plans/paid-newsletter-subscriptions.md and docs/business-plans/data-cleaning-conversion-gigs.md. Sample translation retains the harness’s full-site field and source-page topic; whole-page translation retains CLI document context.

Live Wiktionary requests returned HTTP 429, so the reported comparison uses a **frozen cached-public-data replay**, not a successful fresh live crawl. A temporary --import preload indexes repository public fixtures by title and host, then overlays a frozen index of 27,269 pages from the existing English Wiktionary cache (including redirect aliases). It answers missing lookup, Wikidata, corpus and rendered-morphology requests with no hits. It makes no HTTP requests. Missing records are therefore lookup gaps, not evidence that a word is absent from Wiktionary. Identical preload, page index and cache were used before and after. This is a conservative, grammar-focused audit; rates do not estimate fresh-online performance.

The raw replay inputs and logs remain in /tmp/site-audit; pages.json is the frozen 118 MB public page index (not checked in). Its SHA-256 is 54e1e7b93589c2cdc34c413c00a7297dadb38e12ba299058cb2492eeb5a31752. The [replay](site-audit/replay.mjs) and [index-building](site-audit/build-index.mjs) scripts are retained in this audit directory. Rebuilding the index from a later cache can change vocabulary; retain the original pages.json and full-cache directory for an exact replay. HTTP User-Agent code was unchanged; offline fetch fixtures assert the required value. No vocabulary overrides or word-to-word production mappings were added.

```sh
NODE_OPTIONS='--import=./formal-ai/docs/site-audit/replay.mjs' FORMAL_AI_CACHE=/tmp/site-audit/full-cache node formal-ai/scripts/sample.mjs sentence 40 17
# repeat for seeds 42 and 73; sentence 30 99 for the holdout
NODE_OPTIONS='--import=./formal-ai/docs/site-audit/replay.mjs' FORMAL_AI_CACHE=/tmp/site-audit/full-cache node formal-ai/bin/formal-ai.mjs translate --file docs/business-plans/paid-newsletter-subscriptions.md --json
# repeat for docs/business-plans/data-cleaning-conversion-gigs.md
```

Completeness uses the actual CLI/harness complete flag: no unknown tokens, no parser leftovers and no opening square bracket in Russian. It measures coverage, not adequacy or fluency. A preserved Markdown link can contain untranslated English while remaining complete under this metric. All failures below are the union of bracket-containing and CLI-incomplete units. Counts are **sentence occurrences**, including repeated headings in separate pages; the holdout is excluded from cause ranking.

## General rules added

1. **Nonfinite/nominal attachment.** English agreement separates attributive -ing subjects from nominal actions (Reading students write versus Reading students helps). A verb reading also compatible with adjective + noun does not prematurely terminate a gerund’s object. A nominal heading can retain a purpose infinitive with an explicit object; sense selection sees that infinitive’s actual object. The Russian noun phrase renders the purpose using для того, чтобы. Complete imperative infinitives keep precedence over nominal reinterpretations.

2. **Passive participles/reduced relatives.** A nominal head before a terminal participle remains a noun even if it also has an adjective reading (Capital required). Comma-delimited reduced passives attach to their noun, retaining adverbs and PPs; ambiguous base/past forms keep their finite coordination reading. If a Russian long participle is unavailable, a finite relative follows the complete noun phrase, using the existing verb, object government, agreement and explicit agent when present. Existing attested participles remain unchanged.

## Validation and remaining problems

Validation on the final changes: the three new offline tests pass; `npx eslint formal-ai tests` passes with no warnings; `npm run check:file-size` passes; changed files were formatted with `npx prettier --write`. The full `node --test --test-timeout=60000 tests/` run (with localhost access for server tests) reports **457 passed, 1 failed, 458 total**. The sole failure is the known concurrent production replay manifest: 76 recorded English sentences versus 84 requested (eight newly added sentences lack expected rows). It fails before translation comparison. No test expectation or concurrent public fixture was rewritten to conceal that failure. Thus the all-tests-pass requirement remains unmet until those concurrent fixtures are completed.

Remaining coverage gaps include lexical do, bare infinitive control, subjectless modals and participles, quantifier ellipsis, complex monetary lists, possessive names, quoted/foreign expressions, and missing vocabulary/POS readings. The finite-relative fallback improves coverage but cannot repair an already wrong sense, missing preposition government, or an incorrect antecedent: the shop/paid coordination and get-paid examples remain semantically awkward despite becoming complete. Cached names and untouched Markdown links also need a separate adequacy audit. No claim of human-quality translation is made.
