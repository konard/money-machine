# Non-sentence lines and quantity evaluation

Continuation completed on 2026-11-04. No commits were made. This report preserves the 40-unit list recovered from the interrupted run and records Russian output for every unit, including unchanged and still incorrect translations.

## Implementation

- `src/english/clause.mjs`: adjective fragments, negative participle labels, agreement with the label values, and terminal label punctuation.
- `src/document.mjs`: preserve separate plain-text lines when each parses as a complete fragment; continue joining ordinary wrapped prose.
- `src/english/parser.mjs`, `quantity.mjs`, `verb-group.mjs`: quantified nouns, scalar degree, adjective/adverb degree and comparison complements; keep degree operators out of ordinary adverb consumption.
- `src/formalize.mjs`: retain degree, bounds, amount measurements, fragment properties, and label agreement in the meta-language.
- `src/russian/degree.mjs`, `phrase.mjs`, `copula.mjs`, `naturalize.mjs`: render nominative fragments, quantity government, agreeing participles, analytic attributive comparatives, dictionary-supplied predicate/adverb comparatives, and comparison punctuation.
- `src/forms.mjs`, `resolve.mjs`: retrieve missing comparative forms for existing entries from Wiktionary; retain comparative tags on newly resolved entries.
- `src/english/analyze.mjs`: recognize Unicode currency symbols. Currency amount + noun phrases preserve the amount and use genitive agreement; Indian grouping is localized.
- `src/senses.mjs`: selectional restrictions can inspect passive subjects and label values. It still chooses the lexical sense; there is no special translation for “covered”.
- Lint repairs in `src/senses.mjs`, `src/sources/verb-frames.mjs`, `src/sources/wiktionary.mjs`, `parser.mjs`, `quantity.mjs`, and `verb-group.mjs`.
- `tests/formal-ai/verb-frames.test.mjs`: repaired malformed translation-table fixtures, unique complete test concepts, source morphology and async warnings. `constructions.test.mjs`: corrected expected agreement for plural passive labels. `lines-quantity.test.mjs`: added offline end-to-end cases with a stub public API and User-Agent assertions.

All lexical content remains dictionary/lexicon data. New language tables contain grammatical operators only. No runtime dependencies were added.

## Comparison method and limits

The 40-unit input list is the interrupted run’s `/tmp/fragment-review-units.json`. The baseline uses its recovered `/tmp/fragment-original` grammar modules over the continuation-start source tree. That recovered baseline already contains earlier fragment support; it is not a pristine Git checkout. The retained noun-phrase examples can therefore be unchanged on both sides.

Both sides use the same frozen raw public-source cache copied at continuation start, the same source adapter, and the original page as topic. Missing cached responses return empty data; no new network data was fetched for the comparison. Only the isolated evaluation copies disable the request-spacing delay. Production request spacing and User-Agent remain unchanged. A live cache produced unrelated lexical drift during an initial comparison, so that run was discarded and both sides were rerun with the frozen cache.

Frozen source data is incomplete: many units have unresolved words, bad senses, or broken clause structures on both sides. Ten of the 40 outputs change (units 2, 3, 17, 20, 21, 25, 28, 30, 34, 37). These counts measure changed strings, not correctness.

## Remaining problems

- Country coverage remains a sense-selection failure: the label now agrees in the plural, but still chooses «закрыты», rather than a coverage/support sense. The grammar fix does not solve this lexical issue.
- “Gift cards come in fixed denominations” still chooses wrong senses for both the verb and denomination. No word-specific substitute was added.
- Rank/tier labels, noun compounds, infinitival noun modifiers, unknown names, coordinated predicates, multipliers such as “2–5x more”, and several longer website sentences remain poor or partly untranslated.
- Nominative noun fragments work when the lexical readings are available, as the offline cases demonstrate. The frozen cache lacks enough vocabulary for many of the 40 website units.
- Comparative clauses and degree scope are still limited when upstream parsing fails; correcting the degree operator does not repair the rest of those sentences.
- The random sample contains many pre-existing lexical and grammatical failures. Passing tests and unchanged completeness do not mean this task has made the entire website translation acceptable.

## Live follow-up, 2026-11-04

This section supersedes any implication that the earlier offline fixtures establish live quality for these constructions. I did not create a commit. A concurrent process moved the shared HEAD to `5ae5ef4` during the work; this report does not imply that the repository history stayed unchanged. The requested commercial sense of “listing” and the geographic coverage sense are **not fully fixed**.

### Retained changes

- `src/english/clause.mjs`: recognize a complete NP before a colon as a label, including ambiguous noun/verb heads; prefer parallel adjective + noun fragments over an imperative interpretation of comma-separated lists, including lists ending in a period.
- `src/english/analyze.mjs`: a capitalized negator cannot acquire a competing name reading; an adjective before a noun keeps its lexical reading at the start of a label even if document name guessing proposed it as a name.
- `src/english/function-words.mjs`, `parser.mjs`, `src/russian/words.mjs`: add the closed-class indefinite pronoun “others”, its plural feature and Russian case paradigm. This is grammatical pronoun data, not a content-word translation exception.
- `src/sources/wiktionary.mjs`: read `multitrans`-wrapped translation tables and their `trans-top-see` cross-references. Previously “list” lost its productive dictionary senses. On equal definition/gloss overlap, prefer fewer unrelated content words and break equal-specificity ties in favor of a leaf definition, so nested definitions retain the right valency evidence.
- `src/resolve.mjs`: decide whether a capitalized unknown needs Wikidata by its actual readings, rather than whether Wiktionary was already queried. “Armenia” was marked queried before name eligibility was checked and was incorrectly skipped. Also retain dictionary converb forms.
- `src/forms.mjs`, `src/russian/nonfinite.mjs`, `phrase.mjs`: complete Russian converb forms for English gerunds, and render instrumental “by + action” as an adverbial clause with its dependents and a comma. Productive imperfective `-ать/-ять` morphology remains a fallback when a dictionary form is absent; this does not cover every irregular verb.
- `src/senses.mjs`: currency, percentage and range tokens no longer manufacture repeated “amount” and “value” lexical matches. Bare numeric counts retain their previous behavior. Expanding the dictionary tables initially made “rendering rates” choose «пропорции» because these synthetic matches overwhelmed the real word “fee”; the retained change restores «ставки».
- `tests/formal-ai/lines-quantity.test.mjs`: stub public APIs, assert the User-Agent, and cover wrapped tables and cross-references, method gerunds, ambiguous NP labels, capitalized negation/adjectives, pronoun coordination, queried unknown names, and the numeric-cue regression. Existing offline tests continue to cover bare PayPal and bounded quantities.

Required lint-only formatting was also applied to shared concurrent additions in `senses.mjs`, `src/sources/context-frequency.mjs`, `sense-data.mjs` and `src/russian/copula.mjs`; their business-sense/corpus behavior belongs to the concurrent work. No per-content-word English→Russian override was introduced. HTTP identity remains `formal-ai-translator/0.1 (https://github.com/konard/money-machine)`.
