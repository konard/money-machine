# Business verb senses and whether/if evaluation

Recorded 2026-11-04. No per-word English-to-Russian overrides were added.

## Implementation

- `src/senses.mjs`: plural stemming preserves sale/sales and royalty/royalties; a word does not count as its own topic cue. Added traceable corpus evidence for a verb and its object (the subject of a passive), conservative dictionary usage and related-page penalties, and field evidence for borrowed translation definitions. New corpus evidence is used only for fully parsed, known input.
- `src/sources/context-frequency.mjs`: cached public Russian Wikipedia counts of dictionary verb/noun lemma pairs, including infinitive objects. Only dictionary lemmas are queried; user sentences and names are not sent. Failed/absent counts supply no evidence.
- `src/sources/sense-data.mjs` and `src/resolve.mjs`: empty translation tables may inherit a sibling translation with the same definition head, retaining their own gloss. Rare/obsolete labels remain visible to scoring.
- `src/sources/wiktionary.mjs`: a parent definition does not inherit all nested definitions' grammatical frames. Dictionary order remains the tiebreaker for matching translation glosses.
- `src/english/{function-words,clause,parser}.mjs` and `src/russian/{naturalize,copula}.mjs`: whether and interrogative if become verb-first ли clauses; conditional if remains если. Future/modal groups place ли after their finite auxiliary. A noun/verb before an adverb can be recognized as the finite verb.
- `tests/formal-ai/business-senses.test.mjs`: five offline tests, including stubbed public API responses and User-Agent checks.

## Method and checks

The before column uses the previous run's frozen `business-before-frozen.json`, not a new baseline generated after editing. The after column uses the same 68 English inputs and saved page topics, with the full site supplied as the field. Public dictionary responses are reused from the local cache; missing corpus pair counts were fetched from Russian Wikipedia. These are observations against those responses, not a promise that live dictionaries never change.

There are six requested examples, 44 additional targeted website/document units (26 complete sentences and 18 fragments), and a fixed-seed sample of 30 website units. The extra 12 complete Markdown sentences use the saved pre-change translator copy for their before column, with the same dictionary cache and page topics as the after column. The sample deliberately retains the original extraction (including fragments and difficult sentences).

- 12-case sense harness: **7/12**, preserving the original aggregate score; royalty now passes, while the platform case still fails in the isolated harness.
- Random sample: **27 unchanged, 3 improved, 0 observed regressions**. Improved: redeem, booking, and list a garage. Existing parser/lexical errors in the unchanged outputs remain.
- Full tests: **214 passed, 0 failed** (`node --test --test-timeout=60000 tests/`; localhost permission is needed for the server tests).
- ESLint: passed for `formal-ai tests`.
- File-size check: passed; every JavaScript file is at most 1000 lines.
- Prettier: applied to task files. Nothing committed.

## Remaining problems

- Message still selects an SMS verb: the current dictionary route exposes `смснуть/эсэмэсить`, not `написать`. Russian government is honored when present in source data, but the requested `написать вам` has not been reached.
- Allowing a payment delay remains `Учтите 3–5 дней для платы`; the stronger reserve/plan-time rendering is unresolved.
- The whether clause is now parsed and rendered with ли, but shipping still needs an attested intransitive/reflexive delivery sense, a commercial item sense, and direction: current `отправляет ли предмет за границей`, desired `отправляется ли товар за границу`. The exact desired clause passes with offline dictionary fixtures that provide those senses; live-source resolution remains incomplete.
- The other five sense-harness failures and many pre-existing sentence/parser errors remain. In particular the aggregate 7/12 must not be read as all original cases individually preserved.
